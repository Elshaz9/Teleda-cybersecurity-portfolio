# Active Directory

This section documents hands-on Windows domain administration and security configuration in a controlled lab.

## Topics

- Domain and DNS administration
- Organizational Unit design
- User and security group management
- Group nesting and role-based access concepts
- Group Policy configuration and application
- Workstation security baseline validation
- Windows security auditing and privileged account events

## Documentation approach

For each exercise, I will record the objective, configuration path, relevant commands or Group Policy settings, validation evidence, and operational or security significance. Domain names, user identifiers, and system details will be generalized where appropriate for public sharing.
