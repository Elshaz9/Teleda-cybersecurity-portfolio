# Security Monitoring

This section covers the monitoring tools used in my lab and how I validate that telemetry is collected and useful.

## Wazuh

Work includes agent onboarding and health checks, Windows event collection, archive and alert review, and investigation using Discover / DQL.

## Suricata

Work includes IDS deployment, interface monitoring, rule testing, alert interpretation, and review of EVE JSON events.

## EveBox

Used to review and investigate Suricata events in the lab.

Configuration notes will distinguish lab-specific settings from general guidance and will not include secrets or sensitive deployment details.
