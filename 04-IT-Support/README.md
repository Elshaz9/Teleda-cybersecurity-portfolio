# IT Support

This section will contain practical troubleshooting and support exercises across Windows and Linux systems.

Planned documentation areas include:

- Windows system and network diagnostics
- DNS and connectivity troubleshooting
- User and permissions support
- Disk space and storage investigation
- Service and application troubleshooting
- Virtual machine and lab maintenance

Each entry will include the symptom, checks performed, root cause when established, resolution, and verification.
