# Evidence Index

This folder is intended for selected, sanitized evidence that supports the project reports.

## Evidence handling

- Remove passwords, tokens, keys, personal data, and unrelated account identifiers.
- Review screenshots for browser tabs, paths, hostnames, domain details, and notifications that should not be public.
- Prefer cropped screenshots showing only the relevant setting, event, or query result.
- Give each evidence file a clear name and reference it from its investigation report.
- Do not upload raw log exports or entire workbooks without reviewing and sanitizing them first.

The evidence folder will be populated after the source reports and screenshots have been reviewed.
